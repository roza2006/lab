# 测试策略与计划

## 1. 测试目标与范围
- 确保系统功能符合需求规格说明书。
- 覆盖核心业务流（认证、问诊、处方、流转）。
- 包含单元测试、集成测试、API 测试及前端端到端测试。

## 2. 测试层级
- **单元测试**：覆盖核心领域模型和业务逻辑，使用 JUnit 5。
- **集成测试**：测试数据库交互、外部接口及跨模块调用，使用 Spring Boot Test。
- **API 测试**：验证接口契约和鉴权控制。
- **前端 E2E**：验证关键页面操作和路由权限。
- **验收测试**：基于最终用户场景进行手工验证。

## 3. 环境与测试数据
- 使用隔离的测试数据库。
- 严禁使用真实患者数据，测试数据通过 Seed 脚本生成。
- 包含正常边界及异常数据。

## 4. 角色权限与越权测试
- 必须验证未登录、越权访问其他角色资源（如患者访问医生接口）会被拒绝（HTTP 401/403）。

## 5. 安全测试
- 包括密码加密、JWT 过期/篡改校验、SQL 注入防护和接口限流测试。

## 6. 缺陷分级与准入准出标准
- **准入**：开发自测通过，无严重阻塞缺陷。
- **准出**：所有 P0/P1 缺陷修复，测试报告归档。

## 7. AI 辅助测试声明
本项目在编写测试用例和执行测试过程中可能使用 AI 辅助生成，所有 AI 产出的用例均需经过人工评审和修改。
