## 每轮使用方式

1. **提 PR 前**：作者勾选与本轮改动相关的分组，任何 未落实 都要在 PR 描述里写“本轮不处理的原因”。
2. **评审时**：评审人重点看“新增接口是否复用归属校验”“新增写接口是否带幂等”“新增日志是否脱敏”。
3. **R6 回归**：按全表逐项确认，把结果写进 `docs/test/test-report.md` 与实验报告“安全性”一节。
